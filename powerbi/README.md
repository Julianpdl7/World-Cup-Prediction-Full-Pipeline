# Power BI Dashboard

This folder contains the Power BI dashboard and supporting datasets for the 2026 FIFA World Cup prediction project.

The dashboard presents:

- 2026 World Cup group-stage team performance
- Recent team form
- Historical team performance
- Monte Carlo tournament advancement probabilities
- Model-based knockout-stage analysis

The Power BI datasets were generated using PySpark and the machine learning/simulation results were produced using the project's XGBoost and Monte Carlo pipeline.
