# Power BI Data

This directory contains the datasets used by the Power BI dashboard.

The datasets were generated from the project's PostgreSQL, PySpark, XGBoost, and Monte Carlo workflow.

## Datasets

- `world_cup_2026_group_performance.csv` — 2026 World Cup group-stage team performance
- `world_cup_2026_recent_form.csv` — recent five-match team form through the group stage
- `world_cup_2026_simulation_results.csv` — Monte Carlo tournament simulation results
- `world_cup_2026_team_analysis.csv` — combined 2026 team analysis
- `world_cup_historical_team_performance.csv` — historical team performance
